# React Shopping Cart

A simple shopping cart project built with **React** and **Tailwind CSS** as part of my 30-Day Full-Stack Development Plan.

## Current Progress

### Completed

* Displayed products using React `.map()`
* Created reusable product cards
* Added product images, names, descriptions, and prices
* Implemented **Add to Cart**
* Added cart state using `useState`
* Prevented duplicate products from being added
* Used `.find()` to check whether a product already exists in the cart
* Added shopping cart UI
* Added quantity control interface

### Currently Working On

* Remove items from cart
* Calculate item totals
